# open sourc e real time chat written on nodejs(react framework)


includes:
1. client
2. server
3. profile creation with customization
4.  room creation
5. real-time notification
6. room messages are stored in localstorage
7. profile system (and viewing)

# How to run?

**To run the client:**
> cd client

> npm run dev

**To run the server:**
> cd server

> node index.js
